# Edu4SmartCity

Responsive website for Sawsan Rabi and Edu4SmartCity. Migrated from the supplied website and redesigned using the selected editorial concept with Sawsan's supplied photograph.

The repository root contains the production `index.html` and local `assets/`, ready for GitHub Pages from `main` / root. All navigation is functional and contact links use the original email address. There is no backend or contact-form submission service.

## Development

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

Open `/source.html` during source development. `/` previews the exported production version.

```sh
npm run build
```

Build updates the root production files and retains the starter's Sites-compatible build output. Commit the updated root files with source edits.

## Content and assets

- Original biography, four services, four experience entries, eight credentials, four impact statements and email contact retained.
- Original Edu4SmartCity logo and the supplied photograph of Sawsan Rabi.
- Generated city imagery illustrates the education and sustainability theme.
- Responsive navigation, keyboard focus, skip link and reduced-motion support.

Sources: https://sawsan-edu4smartcity.fey-ash-0206.chatgpt.site/ and the supplied reference images.
